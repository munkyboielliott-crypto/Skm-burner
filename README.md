# Skm – File Format Burner Tool

**Skm** is a desktop-only command-line tool that allows you to copy files to a USB drive and optionally convert their format. It works on **Windows, Linux, and macOS**, providing a simple, recognizable command syntax for safely “burning” files to a thumb drive.

---

## Features

- Copy files safely to a USB drive.
- Optional file format conversion (rename the file with a new extension).
- Detects USB drives by name.
- Easy-to-use command-line interface.
- No external dependencies beyond Python 3.

---

## Command Syntax

```bash
-skm <file_path> <current_format> <new_format_optional> <usb_name>
